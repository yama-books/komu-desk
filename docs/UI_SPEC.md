# UI・操作設計 v0.1

2026-11-26追補：ボタン、アイコン、猫のアセット、アニメーション、Google認証導線の詳細は [VISUAL_SYSTEM.md](VISUAL_SYSTEM.md) v0.2 を参照。共通部品の詳細では追補を優先する。実装は未着手。
Windows 11を第一対象。数値は初期候補で実機検証後に調整。架空のデータでモックを作成する。

## 1. ウィジェット
幅340 DIP（最小280、最大520）、高さは画面作業領域内で可変、96〜200% DPIで検証。タイトルバーを小さく、日付と時計、次の授業、時間割、予定、タスク、同期状態の順。表示するセクションは個別に切替。通常は右端、マルチモニター・解像度変更・タスクバーを考慮し画面外に残らない。
- 初期表示：今日、通常のウィンドウ、最前面OFF。位置/サイズ復元、トレイから表示/隠す/終了。自動起動は任意。デスクトップ固定はWindows実機で安全性と安定性を確認、難しければ通常/最前面/ミニで開始。OSのシェル変更や不安定な内部APIを必須にしない。
- 今日の時間割：時限/開始時刻/学年・クラスバッジ/科目/回数任意/状態。空きは薄い文字、実施済はチェックと低コントラストになりすぎない表現。次の授業は枠線とラベルで強調。終了後は次の勤務日の授業を表示する設定を提供。時刻表示は分単位、カウントダウンは必要なときのみ秒更新。
- 予定：終日→時刻順、同日複数件、授業と重なる予定は小さな警告表示。Google/ローカルの出所と同期の古さを明示。クリックでローカル詳細を開く。
- タスク：今日期限/期限超過/期限なし（表示設定）を順序付け、入力、チェック、完了解除、削除確認。完了済みは折りたたみ。外部連携なし。
- ミニ：時計、次の授業まで、次回の時限・組・科目。展開で通常表示。通知は後続の任意設定、音やアニメーションは既定OFF。

## 2. 管理画面
左ナビ（今日、カレンダー、時間割、計上、進度、タスク、帳票、設定）。最小初期版は今日/時間割/タスク/設定に限定。ウィジェットから対象行をクリックし詳細を直接開く。管理画面を閉じてもウィジェットは継続。未保存編集は閉じる際に確認。
| 画面 | 操作と表示 |
|---|---|
| カレンダー | 月間/週間、日付詳細、年度範囲、今日へ、予定検索、複数日選択で休業候補、行事効果の確認 |
| 時間割 | 曜日×時限のグリッド、セル選択で既存授業グループを設定、空き、移動/交換、貼付け、版複製、適用日確認 |
| 時程 | 開始/終了時刻、時限番号、テンプレート名称、重複検証 |
| 日別変更 | 元の授業、変更内容、理由、対象範囲、変更前後の授業数差、確定、取消 |
| 計上 | 年度/学期/考査間/任意期間、基準日、科目/組、確定/推定/残/見込み/未解決、差の比較、授業一覧へ |
| 進度 | 授業履歴・前回/今回/次回、記録編集、グループ別横断比較 |
| 帳票 | 種類・期間・組・名列含有・A4縦横・プレビュー・印刷/保存 |
| 設定 | 学年/組/科目/グループ、色、年度、時程、計上規則、インポート、Google連携、バックアップ、表示 |
出欠は別途許可を確認した後、管理画面にのみ追加。常駐画面に生徒名・欠席数・個人情報を表示しない。

## 3. デザインシステム
ベースは白/グレー/黒、角丸6〜10、余白4/8/12/16/24 DIP、標準文字14〜16、時刻24〜32、罫線1。Windows標準フォント/同梱フォント。ライト候補 #F7F7F5 背景、#FFFFFF 面、#202020 文字、#606060 補助、#D4D4D4 罫線。ダーク候補 #202020 背景、#2A2A2A 面、#F2F2F2 文字、#BEBEBE 補助、#535353 罫線。
学年とクラスのバッジは並列で表示し、文字を必ず添える。色は任意選択（淡い赤/青/黄/緑/紫/グレー等、カスタム色）。背景と文字のコントラストを計算し、最低4.5:1を目標。色が識別の唯一の情報にならない。科目は普通のテキストを既定。警告もアイコンと文言を併用。装飾は小さな猫の線画を任意配置し、学校で開いて違和感のない静けさを維持。不要なイラストやカードの入れ子を避ける。
キーボード移動・Enter/Esc・フォーカス表示、100〜200% DPI、長い科目名の省略とツールチップ、十分なクリック領域。UI全体に派手な通知色を使用しない。

## 4. 初回利用
デモ/空のデータ/既存Excelの選択 → 年度 → 学年・組・科目・色 → 時間割/時程 → 期間・計上条件 → 取り込み結果の照合 → 表示設定。途中保存可能。Google連携を初回必須にしない。すべて後から変更可能。
操作負荷を減らすため、日常の変更は今日画面から1クリックで詳細、休講等を選択、変更確認で完了。年度/実績に影響する操作だけ明示確認し、色変更など軽い操作に毎回確認を出さない。
