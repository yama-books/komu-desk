# APP-034 Excel初期移行プレビュー
既存の指定形式の3シートを対象にする。年間予定はB列日付/C列名称、時間割は2行目曜日コードB:I・A3:A8時限、日別表は5行目以降D日付/Eコード/G:L授業。7=授業なし、8=考査日。8の日の考査マーカーは授業数に含めず、その他の枠は考査扱い。数式の保存済み値のみを読む。マクロや外部リンクは実行・取得しない。
- 設定 → 既存Excelから初期取り込み → xlsx選択 → 仮学年名・考査計上条件 → プレビュー → 件数とグループ別計上数を確認 → 明示確定。
- 日別表を正本候補として、週間時間割との差分を日別/個別変更に変換。計算結果はグループごとに保存値と一致しなければ反映しない。年度内の取込期間外は未設定。保存値の過去授業を確定実績扱いしない。
- 同日同名予定も保持。名列・出欠・進度・旧集計シートは一切取り込まない。初期の空データ専用。既存データの上書き/繰返し取り込みは拒否。元Excelは読み取り専用。
- 仮学年・時程の確認は利用者が行う。特殊授業、学年またぎ、別形式、複数学期/年度、差分再取込と取消・正式復元は後続。
- テストはその場で生成する合成xlsxのみ。原本は公開Repoに保存しない。実際の添付形式の数値一致はローカル環境で検収する。
