# APP-034 M4a 授業一覧・帳票プレビュー
期間と担当授業を選択し、授業日・時限・状態・回次・実績メモを一覧化する。期間内回次は計上対象のみ。確定、推定、予定を区別。
Excel出力は授業数・授業日/進度の2シートの最小xlsx。入力文字列は式ではなくinlineStr。ローカルのみ、新規ファイルへ書き出し、既存ファイル上書き拒否。印刷はWindowsの選択プリンターを利用し、Microsoft Print to PDF等が使用可能ならPDF化できる（PDF生成専用機構ではない）。実紙の組版・複数ページは要検収。名列は未対象。
前回の実施メモを授業詳細に表示。バックアップJSONの復元は構造検証と件数確認の後に明示確定、直前データを保持。Googleの認証・キャッシュは復元対象外。
学校の既存帳票と完全一致するレイアウト、名列・出欠、年度アーカイブ、複数クラス合同、直接PDF生成は未実装。
