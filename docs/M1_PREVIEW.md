# APP-034 M1 ローカルデスクトップ評価版
初期実装候補：C# / WPF (.NET 10)。WindowsネイティブのGUI、ブラウザ/WebViewなし、標準ライブラリのみ。Tauriは柔軟なUIに適するがWebView2の動作・通信監査が増えるため、まずWPFの最小版を評価する。実際の資源負荷・起動権限・ネットワーク観測は未測定。実機評価後に最終採用。
## 実装範囲
- 日付と時計、次の授業/授業中、曜日別時間割、学年/クラスの色バッジ、空き表示、ローカル予定、チェック式タスク。
- 学年・クラス・科目・担当授業・時程・週間時間割・有効期間・年度・表示設定を編集。最前面、ミニ表示、起動時の位置/サイズ復元。
- 日別全休/曜日変更、時限単位の休講/置換・追加、考査計上切替、授業数集計（確定/推定/残）、終了後の実績確定とメモ。正式な振替リンク・合同・時程テンプレート・学期区分は未実装。
- ローカルJSON（暫定保存形式、SQLiteへの移行をM2で検討）。標準保存先は LocalApplicationData/KOMU DESK/data.json。一時ファイル→置換、直前スナップショット、明示バックアップ。名列を扱わない。正式な復元UIは未実装。
- デモは架空データ、保存しない。初期起動は空データ。Google連携・外向き通信コードなし。校務PCへの導入は管理規則に従う。
## 実行
Windowsの開発環境で `dotnet run --project src/KomuDesk.Desktop -- --demo`（架空データ）。通常起動は --demo を付けない。GitHub ActionsのWindows self-contained publish評価用ArtifactはZIP展開後の KOMU-DESK.exe を使用。未署名、正式配布ではない。Windows実機は未確認。
