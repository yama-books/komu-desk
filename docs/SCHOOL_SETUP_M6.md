# APP-034 M6 school setup, calendar import and day schedule
v0.1.11 candidate, based on v0.1.10. Original workbook structure inspected locally; no real workbook, names or events committed. Existing three-sheet initial importer remains, including cache comparison and no confirmed actuals. Additive import supports .xlsx selected sheet, date/title/optional time columns, start row, per-row preview (new/existing/unresolved), drag-drop on calendar and TSV paste. Reimport compares multiplicity of exact date/title/time; no delete or automatic replacement. Changed titles/dates appear as additions and need user review. Monthly grid or merged-cell non-tabular layouts and arbitrary Excel formulas are not supported; original source is not modified.
Teaching setup: editable grade/subject choices, comma/newline-separated classes and existing-class buttons; reuse existing exact names and IDs. Weekly palette with erase, 7 days, period count and explicit Excel grid paste by unambiguous group labels. Five/six columns intentionally replace whole selected version including weekend after explicit confirmation. Existing detailed group settings retained. ActualLesson records are unchanged by edits.
Special profiles: named bell subsets copied from normal, real start/end supplied by teacher; no fabricated short-times. Missing periods and explicit cutoff cancel ordinary planned lessons; explicit replacement outside permitted period becomes unresolved; confirmed actuals always win. Applied profiles are immutable through editor (create new profile). DayChange combines weekday/profile/cutoff and closure. Calendar, widget and counts share LessonEngine. Schema remains 1 for unchanged data; save upgrades to 2 when extended scheduling features present, older versions reject instead of dropping fields. Before rollback after using new settings, backup and restore a pre-upgrade copy with compatible schema; do not overwrite newer data.
Rules: exact normalized title and source (local or selected cached Google calendar). Built-in weekday/limit/closure and matching profile suggestions, no automatic by default; ambiguous festivals/exams and unknown short profiles are review only. Separate same-day compatible signals compose; conflicts block. Future only automatic after explicit rule activation and import, local event edit or manual Google sync. Existing day/period changes, confirmed actuals and past days blocked. Once applied, a change is a local explicit day record; later source changes/deletions do not silently undo it. Manual day edit remains available. No new runtime dependency or network. Source sheet data and credentials stay local. Physical Excel import, real OAuth and actual UI/printing verification separate from hosted fixtures.
