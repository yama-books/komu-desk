# APP-034 / v0.1.7 retention and icon quality
## Retention
The user requests one previous version by default. Existing data.json Display.UpdateKeepPrevious defaults to 1; 0/1/2/all (-1) in Update settings. Cleanup runs only after a successful normal non-demo shutdown with saved local data, no pending update or rollback, and only when the running directory is the active managed version. It never cleans manual extracts, the original launch folder outside versions, school data, authentication, backups, active or newer version, or unknown names. Current pointer must match. Keep all copies of the most recent N distinct older versions; same-version duplicates are conservatively preserved. Exact GUID/tag naming, assembly identity/version, no reparse points anywhere in path/tree, file-set match against staging manifest (new) or subset of known current package files (legacy); unexpected files are preserved. Locked/unsafe directories are skipped, not forced. New staging records file list after validated ZIP and preflight; no remote transfer. Failed download work is cleaned by existing finally block; crash remnants without provenance and manual folders remain for user review. Existing pinned shortcuts pointing directly to a deleted managed old version may need re-pinning. No automatic cleanup on manually launched non-managed copy; update-managed current version required. Existing rollback via --no-update-redirect is unchanged.
## Icon improvement
Recrop actual approved original sheet (1536x1024). Ten 128x128 transparent charcoal masters, four alpha levels for compact storage, then resample each size individually from the master via Lanczos; output 8-bit alpha, no artificial white halo or binary threshold at the output. 16/20/24/32/40/48/64/128/256 (256 is upsampled from 128). Dark ink and light ink variants of each; Windows SystemUsesLightTheme at startup/selection/DPI change, no polling. Small frames 32-bit BGRA DIB, large PNG frames. Existing IDs/selection remain. WPF picks nearest frame based on DPI, notification icon uses nearest small frame. Default exe remains cat-02 dark variant. Windows Explorer cache/pinned shortcuts and actual monitor DPI/theme require user-side visual check. Generate via scripts/generate_tray_icons.py (Pillow build-only); generated ICOs committed to GitHub, no runtime dependency. Actual theme changes while running are not monitored; restart or select again.

Existing data and updater preserved. No Google OAuth change.
