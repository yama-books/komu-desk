## Necessary small improvements v0.1.3
- Adopt MSIX-style startup throttling: 12h after a successful check, 1h after a failed attempt; manual check always allowed. Store only last attempt/success UTC and observed tag locally. No poller, no auto-download.
- Adopt PowerToys-style unobtrusive notice: small widget update badge rather than interrupting startup with modal. Display last successful check, last attempt, and cached newer tag; only a fresh successful check enables applying. Clear stale offer on failed manual check.
- Require GitHub ZIP asset digest (sha256) in addition to same-release SHA256SUMS and existing byte verification. Incomplete newest preview is error, not falsely reported as latest. Bound metadata response and progress events, check cancellation before switch. Preserve full ZIP fallback approach (only full ZIP today).
- Keep preview-only channel until an actual stable release exists. Do not silently downgrade. Avoid importing external libraries or changing installation format just for these fixes.
## Deferred / conditions
NetSparkle signing and GitHub immutable release/attestation are important release trust practices, not implemented just by checksum. Current release metadata immutable=false; repo setting changes require separate owner action/approval. No private key in repository or application; independent signature/Authenticode key custody and verification policy needed before formal school distribution. No claim of strong publisher authentication for previews. Velopack remains a migration candidate if delta updates, standard installation, shortcut/rollback lifecycle or maintenance burden justify it. MSIX needs packaging/signing and school policy; do not impose it on portable evaluation. No differential updater, automatic removal of old versions, silent install, services, task scheduler or dependency expansion now. Disk use grows with updates; retain old directories for manual rollback, review retention only with a safe policy. Actual two-release user UI update and managed school PC/network still need acceptance. No third-party code copied.
