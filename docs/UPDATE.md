# APP-034 GitHub Releases 更新仕様 v0.1
2026-11-27 / ユーザーの明示要望による通信例外。対象 v0.1.2-preview。
- 起動時チェックは既定OFF。設定→アプリのアップデートで有効化、または「今すぐ確認」。Google連携とは独立。デモは通信なし。通知後に本人が適用を承認し、無断ダウンロード・無断実行なし。現時点は評価版チャンネル vX.Y.Z-preview のみ。
- 固定Publicリポジトリ yama-books/komu-desk の Releases API と固定名ZIP/チェックサムのみ、HTTPS、許可したGitHub配布ホストへの限定リダイレクト。認証不要。校務データ、名列、Googleトークン、ログを送信しない。GitHubには通常の接続情報が伝わる。
- 数値バージョン比較、上限付きダウンロード、SHA256SUMSの照合、API digestが存在すれば照合、ZIPパス・重複・サイズ・リンク・不要データ検査、実行アセンブリ版の照合。検証後、架空デモの試験起動に成功したもののみ切替候補。チェックサムは同一配布元の整合性検査であり独立署名ではない。未署名の評価版。GitHubアカウント/供給網侵害への完全な防御ではない。正式版は署名方針を別途決定。
- LocalAppData/KOMU DESK/versions に新規フォルダで展開。元のexe・フォルダは変更しない。現アプリの通常終了と保存に成功した後、新版を起動し旧プロセス終了を待つ。初回描画後にactive.txtを原子的に更新。旧版（v0.1.2以上）を引数なしで起動すると有効な新しい版に転送。既存ショートカットはそのまま使用可（v0.1.1以前は非対応）。失敗時は旧版が残る。手動復旧：旧版exeを --no-update-redirect 付きで起動（active.txtを解除）。初回描画後の不具合まで自動ロールバックする機構ではない。古い版の削除は自動で行わない。
- データとGoogleキャッシュは従来のLocalAppData直下の同じ場所、更新フォルダとは別。DB・設定・認証の移行なし。更新確認の許可は別ファイル。学校のネットワーク/アプリ実行規則を優先。許可されない場合OFFで手動配布。
- v0.1.2は最初の更新機能付き評価版のため一度だけ手動ZIP取得。次版からアプリ内更新。実Windows上で実配布版間の遷移、ネットワーク遮断、ユーザー操作、旧版復帰を検収する。現時点は自動テストとビルドを先行、実機の完全検収とは区別。

## v0.1.3 先行事例に基づく補強
[UPDATE_REVIEW.md](UPDATE_REVIEW.md) を参照。自動確認の最短間隔は成功12h、失敗1h。手動確認は制限なし。通知はフッターの「更新あり」のみ、前回成功/試行時刻を表示。キャッシュは通知用であり、更新実行は新たな成功確認の情報を使用。GitHub asset digestを必須とし、新版の不足/不正は確認失敗扱い。APIレスポンス4MB上限、進捗通知を抑制。既存の配布方式、通信先、評価版チャンネル、適用確認、旧版保全は変更しない。署名・immutable release・差分配布は別工程。
