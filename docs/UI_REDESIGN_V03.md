## 1. 現行と目標
現行 DeskWindow/WidgetSkin はコンパクト常駐、BentoMenu の19操作（従来18＋アイコン）は個別ダイアログへの入口。LocalEvent は日付・時刻（空欄は終日）・題名、Todo は題名・期限・完了、LessonEngine.Day/Count が授業の正本。GooglePanel は選択済みカレンダーのローカルsnapshotを日付判定して表示する。月/週/日/一覧を統合する独立画面は未実装。Google実認証未検収。新しいカレンダーは既存データの投影であり別DBを作らない。
小さなウィジェットは維持し、単一の管理ウィンドウを追加/再利用する。管理ウィンドウを閉じてもウィジェット継続、ウィジェットの×は従来の終了（未保存確認含む）。管理画面をタスクトレイ/ウィジェットの対応操作から直接開く。初期案: 幅340〜370（280〜520を維持）、管理1040×720 DIP、最小720×480を目安に画面作業領域へ収める。狭幅は折畳ナビと縦積み、横スクロールは表だけ。ウィジェットに常時サイドバーを入れない。
## 2. 共通外観/独自バー
Canvas #F7F7F5, Surface #FFFFFF, Ink #202020, Secondary #606060, Border #D4D4D4。角丸8〜10、間隔4/8/12/16/24、文字13〜14/補助11〜12、見出し20〜24。バッジのみ学年・組の登録色と文字、コントラストを確保。共通WidgetButtonの押下98%/1 DIP、70ms・復帰120〜150msを継承、操作に必要な部分だけ更新、動き削減時は即時、常時装飾なし。
独自バー: 左に選択中猫アイコン＋KOMU DESK＋画面名、中央は余白（広幅時のみローカル/同期状態）、右に最小化・最大化/復元・閉じる。ウィジェットは固定/ミニも必要、狭幅ではタイトル省略し操作を確保。WindowChromeとSystemCommandsを優先、CaptionHeight/ResizeBorderThickness、操作要素はIsHitTestVisibleInChrome=true。AllowsTransparency=true を必須にしない。ドラッグ、ダブルクリック最大化/復元、Alt+Space/Alt+F4、四辺リサイズ、画面作業領域・複数モニター・100/125/150/200% DPI、キーボードフォーカスを検証。Windows 11 Snap Layoutの標準ホバーはカスタムボタンで自動保証されないので実機確認し、必要なら標準システム機能への導線を保つ。OSのファイル/印刷/認証ブラウザは標準のまま。タイトルバーに時刻/複雑な状態を詰めない。

## 3. ナビゲーション
管理画面上部共通バー、左176〜184 DIP（狭幅48〜56＋ツールチップ/展開）、右本文。選択は背景＋ラベル/フォーカス。上から ホーム、カレンダー、時間割、授業数、タスク、帳票、区切り、Google連携、設定、アップデート。進度は授業詳細/授業数内入口（独立履歴は既存データを使う後続）、設定はBentoを再利用。画面内の編集/保存/取消は一貫。未保存の編集を破棄して遷移しない。現行19操作の対応: Events→Calendarローカル編集、Weekly→時間割、Tasks→タスク、DayChanges→カレンダー/時間割の日別変更、Counts→授業数、Reports→帳票、Grades/Classes/Subjects/Groups/Bells/Versions→設定の授業設定、Year→年度/表示、GoogleSettings→連携、ImportExcel/Backup/Restore→設定データ、Updates→更新、TraySettings→外観。重複する入口は同じ処理を呼ぶ。廃止操作ゼロ。
## 4. ウィジェット / ホーム
ウィジェット: [猫 KOMU DESK | 固定 ミニ 最小化 ×] → 日付前後/今日 → 時計と次授業 → 時間割 → 予定 → タスク → 状態/管理入口。日付変更は同画面で全セクションを同期、今日で戻す。日付/予定見出しから管理カレンダーに選択日を渡す。現在日でない時は次授業カウントダウンが現在時刻のものと混同しない表示。時計更新で日付選択・編集中のコントロールを再生成しない。
管理ホーム: 上部 今日の日付/現在時刻/次授業、中央左右 今日の時間割・今日の予定、下部 今日/期限超過タスク・クイック操作。狭幅縦積み。授業詳細は既存LessonEngineと確定/メモ処理へ、架空の機能ボタンを置かない。
## 5. カレンダー（第一優先）
共通ツールバー [前][今日][次] [2026年11月] [月|週|日|一覧] [表示対象] [同期] [＋予定]。月/週/日はそれぞれ単位で前後、一覧は選択範囲単位、今日で選択日と期間を更新。ページ内に選択日、表示モード、表示期間、フィルタ、選択イベントIDを持つ。月曜始まり既定、土日も表示、6週×7列を基本、当月外薄色。今日と選択日を異なる輪郭/背景/読み上げで示す。選択日を別ウィンドウで選ばせない。
月: 左約2/3（月グリッド）、右約1/3（選択日詳細）。セルは日付＋短い予定名を最大2件（狭幅は種類別件数）＋残り「ほかN件」。選択日にクリックで右側即更新。右側は日付、終日予定、授業と時刻付き予定（開始順、授業にはバッジ/状態）、タスク（期日当日）、日別変更入口。月を移動しただけで保存・同期・授業確定しない。狭幅は上に月、下に詳細。選択日の詳細を常時表示（必要ならスクロール先に誘導）。
週: 7日列、終日行＋日別の時刻順リストを第一実装とする（複雑な重なりタイムグリッドは後続）。選択日詳細を同画面に残す。日: 日付ヘッダーと終日/時刻順の全項目、タスク別枠。時刻不明/期限だけのものに架空時刻を割当てない。
一覧: 今日/今週/今月/任意範囲、開始/終了を同ツールバー内で設定、日付見出しごとに終日→時刻順→タスク。空の日は省略可、範囲全体の空状態を表示。既定31日、任意範囲は最大366日を初期上限、長いリストは仮想化またはページ分割。スクロール中も範囲とフィルタを保持。
表示対象: ローカル予定/Google予定/授業/タスクの4独立チェック（既定全て）。完了タスクは既定非表示、オプションで表示。予定のない日、未設定日、同期対象外、取得失敗を区別。年度外は授業未設定、Googleキャッシュ範囲外は未取得と表示。日付選択自体は年度外も許す。新しい期間を見ただけでGoogle通信しない。同期は明示操作、現行年度同期範囲を示す。
データ投影: ローカル予定ID、Google calendarId+event id+出現日/開始、授業date+period+group、タスクIDをキーにした表示用の行（Kind, Source, Title, Date, Start?, End?, State, stable key）。同名同時刻だけで別予定を重複排除しない。Google既存OnDate/DisplayTimeを利用、終日終了日排他、複数日/日跨ぎ、取消済み、選択カレンダー、JST日付/タイムゾーンを既存adapterと照合。授業はLessonEngine.Dayの結果、休講/考査/実績を区別、表示から実績を変更しない。タスクは期限日だけ、期限なしはタスク画面に残す。クリックで詳細: Googleは読み取り専用、ローカルは編集/削除、授業は日別変更/記録、タスクは完了/編集。＋予定はローカル追加（選択日初期値）、Google書込み禁止。失敗時は既存キャッシュ保持、最後の同期日時と未連携/未取得を表示。カレンダー選択はウィジェットと開く時点で連携し、明示的な「今日へ」で戻る。管理側の閲覧がウィジェットの今日表示を勝手に変えない。
## 6. その他の画面
時間割: [適用版][期間][編集/複製] → 曜日×時限、学年/クラスバッジ＋科目、選択セル詳細。現行の版・時程・担当授業設定へ遷移。保存前に重複・期間検査、変更が過去の実績を上書きしない。ドラッグ複製等は後続（既存編集維持）。日別変更は日付・元の授業・変更/休講・理由・確定/取消を同画面で確認。
授業数: [開始〜終了][基準日/期間][表示対象][帳票] → クラス・科目別 Confirmed/Estimated/Remaining/Cancelled/Unresolved と現行計上規則、行詳細に授業日一覧・状態とメモ。LessonEngine.Countを再利用。見込みと実績を混同しない。Google予定の自動休講判定は未実装のためボタンを置かない。公式履修判断を自動確定しない。進度は既存ActualLesson.Noteの参照/編集をまず活用。
タスク: [追加][検索][未完了/完了] → 期限超過、今日、近日、期限なし、完了の区分。クリック詳細、チェックは保存成功後反映。優先度フィールドは未実装なので今回追加しない。削除確認、取消、空状態。
帳票: [期間][授業グループ][一覧][Excel][印刷] → 現行LessonReportsを再利用。OS印刷/ファイル保存ダイアログ。名列/出欠は未実装、偽のプレビューを出さない。
Google連携: 未設定/未連携/認証中/選択/連携済/期限切れ/失敗を分ける。共通clientの管理者設定は詳細へ。認証ボタン・選択カレンダー・手動同期・最終取得・解除。実OAuth登録や共有配布条件は別工程、認証情報を保存/公開しないとの意味は公開Repoに載せないこと（ローカルDPAPIは維持）。Google書込み/Tasksなし。
設定: Bento 3区画（授業設定、外観・年度、データ管理）。授業設定に学年/クラス/科目/担当授業/時程/時間割版、外観にアイコン10種/年度/表示、データにExcel取込/バックアップ/復元。よく使う操作は主ナビへ。未実装設定を操作可能に見せない。既存19操作すべて到達可能。
更新: 現在/新版/最終確認、確認・適用、工程表示/中止、旧版保持設定0/1/2/all、既定1。更新処理・削除範囲・失敗時保全は既存を維持。
